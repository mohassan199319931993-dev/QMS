# نظام إدارة الجودة - Quality Management System

## 📋 نظرة عامة

نظام متكامل لإدارة ومراقبة جودة الإنتاج، يوفر واجهة مستخدم حديثة وسهلة الاستخدام مع ميزات متقدمة للتحليل والتتبع.

## ✨ المميزات

- 🔐 نظام تسجيل دخول وخروج آمن
- 📊 لوحة تحكم تفاعلية مع مخططات بيانية
- 📝 إدخال وإدارة بيانات الجودة
- 📋 سجلات الجودة مع البحث والفلترة
- 📈 تحليلات وإحصائيات متقدمة
- 📚 مكتبة المستندات والموارد
- 🤖 مساعد ذكي للإجابة على الاستفسارات
- ⚙️ إعدادات متكاملة للنظام

## 🗄️ قاعدة البيانات

قاعدة البيانات في ملف Excel تحتوي على الأوراق التالية:

1. **المستخدمين** - بيانات المستخدمين والصلاحيات
2. **الموديلات** - معلومات الموديلات والمنتجات
3. **سجلات الجودة** - سجلات فحص الجودة
4. **العيوب** - تفاصيل العيوب المكتشفة
5. **المستندات** - الملفات والمستندات
6. **التحليلات** - المؤشرات والمقاييس
7. **إعدادات النظام** - إعدادات النظام
8. **سجل النشاط** - سجل العمليات
9. **مصطلحات الجودة** - معجم المصطلحات

## 🚀 طريقة الاستخدام

1. افتح ملف `login.html` في المتصفح
2. سجل الدخول باستخدام إحدى الحسابات التجريبية
3. استكشف لوحة التحكم والميزات المتاحة
